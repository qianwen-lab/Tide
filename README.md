# Tide PWA V5

Tide is a local-first weight-goal and daily-plan tracker designed for iPhone Safari / Add to Home Screen.

## V5 highlights
- Chinese-first UI with a cream + jewel blue + coral + green palette
- Compact Today page with the dynamic reminder near the top
- Calendar dots only appear when meaningful thresholds are met
  - Food: at least 4 core items completed and >=80% on plan
  - Movement: >=10,000 steps OR Cardio OR Strength
- Weekly goal uses number of 10k-step days (not a configurable daily step target)
- Active Goal reads the start-date weight dynamically; archived Goals are frozen snapshots
- `schemaVersion: 5` data migration preserves older Tide records across upgrades
- Default targets merged into one settings entry
- Custom day can override both food and movement plans
- Improved weight chart spacing and mobile layout
- JSON export/import backup remains available
