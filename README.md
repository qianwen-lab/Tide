# Tide PWA V8.0

Goal Review reading experience cleanup.

- Today now shows the latest Goal Review **Summary** in full instead of the shorter preview.
- The Today link is renamed to **Review history →**.
- Opening Goal Review now defaults to a clean reading view: latest full review first, then earlier review history.
- Export / Paste JSON is hidden until **Add new review** is tapped.
- Previewing a pasted review stays on the review page; Save Review writes the checkpoint and returns to Goals.
- Existing reviews and the `tide.v1` local store remain compatible.
